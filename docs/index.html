Cris Cyborg Boxing

A 2D boxing game featuring Cris Cyborg. Download the standalone edition for your device and take the fight offline.

Windows PC (64-bit)

Download for Windows
  1. Extract the downloaded ZIP file to a folder.
  2. Run CrisCyborgBoxing.exe to start the game.

This is a portable app; there is nothing to install.

Chromebook

Download for Chromebook
  1. Enable the Linux development environment in Chromebook settings.
  2. Extract the downloaded archive in the Linux environment.
  3. Run ./CrisCyborgBoxing from the extracted folder.

The Chromebook edition runs in the Linux development environment on 64-bit Intel/AMD devices. It does not run directly in the Chrome browser.
