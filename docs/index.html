🥊 Cris Cyborg Boxing 89

A 2D boxing game with a downloadable Python desktop edition and an Unreal Engine project. The game features optional Arcade1870 (ARC) rewards - the same system used by Crypto Chess.

Python 3.10+ · Windows, macOS, Linux

Download the Python desktop edition

Download and extract the game source ZIP. Install Python 3.10 or later, then open a terminal in the extracted python folder and run: 

python -m pip install -r requirements-client.txt
python -m criscyborg.client.pygame_client

The Python desktop edition is an offline practice game and requires pygame. The Unreal Engine project is not included in this ZIP as a packaged executable.

Download the game ZIP Unreal Engine releases

Controls: A/D move, J jab, K hook, L special, Space dodge, Esc quit.

Standalone downloads

Choose a build for your device. The Chromebook build runs in the Linux development environment (64-bit Intel/AMD Chromebooks), not directly in the Chrome browser.

Windows 10/11 (64-bit) Chromebook Linux (64-bit)

The Python source ZIP above also works on supported Python desktops. Standalone builds are for the 2D practice game; the Unreal Engine project is source-only and is not packaged here. The 2D game supports high-resolution displays with --resolution 2560x1440 or --resolution 3840x2160; add --fullscreen to launch full-screen.

Arcade1870 (ARC) rewards

Winning matches issues a signed claim against the shared, pre-funded Arcade1870RewardVault smart contract - the exact same vault and ARC token used by Crypto Chess. Connect a MetaMask-compatible wallet in-game, win a match, and submit the signed claim to receive ARC directly in your wallet. The vault only validates a signed claim and doesn't care which game requested it, so the same treasury can safely be shared across multiple Arcade1870 games.

  • Token: Arcade1870 (ARC), an ERC-20 on Ethereum Mainnet
  • Reward contract: Arcade1870RewardVault (EIP-712 signed claims)
  • Players pay their own gas and receive ARC directly - the backend never holds player funds

System requirements

  • Python 3.10 or later
  • pygame, installed using the command above
  • Standalone Windows and Chromebook Linux builds do not require a Python installation.
  • Chromebook Linux build: enable the Linux development environment on a 64-bit Intel/AMD Chromebook.
  • A MetaMask-compatible Ethereum wallet is optional and only needed for online ARC reward claims.
